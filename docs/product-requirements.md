# Product Requirements

## MVP

1. Native app launches quickly.
2. A top-centered notch surface appears even on displays without a physical notch.
3. Hover/click/shortcut toggles compact and expanded states.
4. Clipboard monitoring stores deduplicated history locally.
5. Search supports plain text and composable typed filters such as `@text`, `@link`, `@code`, `@app:Safari`, and `@board:Design`.
6. Copy stack preserves FIFO paste order and supports pausing, reordering, and removing queued items.
7. Boards support create, rename, reorder, delete, membership management, and favorites.

Cloud sync, OCR, media, calendar, and agent monitoring are future phases behind feature flags.
